## 1. 학습 목표 및 완료 시 달성 상태

### 학습 목표
엔터프라이즈 관계형 스키마에 드러나지 않는 **도메인 온톨로지(계층, 상속, 유의어)** 를 Snowflake 테이블로 구축하고, Cortex Agent 가 이를 근거로 질의하도록 연결합니다. 온톨로지가 없는 Baseline Agent 와 **같은 질문으로 비교**해 차이를 직접 확인합니다.

### 완료 시 달성 상태 (결과 쿼리)

| # | 달성 상태 | 확인 위치 · 기대 결과 |
|---|-----------|-----------------------|
| 1 | 엔티티(`KG_NODE`)·관계(`KG_EDGE`)를 테이블로 구축 | `03_` 노드 14(CELL_TYPE 10 + TISSUE 4), 엣지 14 |
| 2 | Recursive CTE 프로시저로 상·하향 탐색, **순환 엣지에서도 종료** | `05_` keratinocyte 조상 4단계, 코호트 조직 4개, [4.0] 순환 시험 후 엣지 14 |
| 3 | 계층 롤업 프로파일 + Cortex Search | `06_` squamous → `bladder, esophagus, lung, skin` / `07_` "flat epithelial…" 1순위 `CL:0000076` |
| 4 | **Cortex Agent 2종 생성·실행·비교** | `08_` [5.4] 실행 SQL 조직 필터: Grounded 가 정답 기준과 일치하는지 |
| 5 | 리소스 정리 | `98_` PART D 3개 SHOW 0행 = `02_` 스냅샷, 2회 실행 오류 없음 |

## 2. 4대 아키텍처 패턴 (외부 인용)

> ⚠️ 아래 수치는 **외부 블로그 인용값이며 이 실습에서 측정하지 않았다.** 원문을 재확인하지 못해 수치도 미확인이다.
> 이 실습이 직접 구현·관찰하는 것은 **1번(Baseline)과 4번(GraphRAG + Terminology Mapping)** 두 구성이며 (`08_`),
> 관찰은 표본 1회다.

```
1. Baseline Semantic View           2. Knowledge Graph (KG)
   Cortex Analyst 1 도구               Stored Procedure 7 도구
   (이 실습: ONTOLOGY_BASELINE_AGENT)   (이 실습: 05_ 프로시저만 구현, Agent 도구 연결은 하지 않음)

3. Flattened GraphRAG               4. GraphRAG + Terminology Mapping
   Search + Analyst 2 도구             Search + Analyst + orchestration 매핑 규칙
   (이 실습: 06_ + 07_)                 (이 실습: ONTOLOGY_GROUNDED_AGENT)
```

| 접근 방식 | 도구 개수 | 인용 점수 (/2.0) | 인용 성공률 | 인용된 특징 |
| :--- | :---: | :---: | :---: | :--- |
| Standard Semantic View (Baseline) | 1 | 0.93 | 50.0% | 계층·유의어 부재 시 한계 |
| Baseline with Knowledge Graph | 7 | 1.14 | 60.0% | 계층 탐색은 정확하나 도구 오케스트레이션 복잡 |
| Baseline with Flattened GraphRAG | 2 | 1.38 | 70.0% | 사전 롤업 프로파일 + 검색, 단순한 구조 |
| GraphRAG + Terminology Mapping | 2 | 1.55 | 78.2% | 복합 용어를 명시 규칙으로 보완 |

### 이 실습의 직접 관찰 (2026-10-14, 표본 1회)

| Agent | 질문 | 실행 SQL 조직 필터 | 정답 기준 대비 |
|-------|------|--------------------|----------------|
| Baseline | Q1 squamous epithelial cell 계통 | `('skin', 'esophagus')` | 불일치 — lung·bladder 누락 |
| Grounded | Q1 | `('bladder','esophagus','lung','skin')` (검색 → Analyst) | 일치 |
| Baseline | Q2 internal organ lining | `('lung','esophagus','bladder','liver')` | 결과는 일치, 필터는 규칙과 다름 |
| Grounded | Q2 | `('lung','esophagus','bladder')` (매핑 규칙 직접 적용) | 일치 |

## 6. 비용 및 리소스 관리

- **지속 과금**: Cortex Search 서비스(`ONTOLOGY_SEARCH_SERVICE`)는 서빙 중 비용이 발생합니다. 중단은 `98_` PART 0, 삭제는 PART A.
- **호출 과금**: Agent 는 `DATA_AGENT_RUN` 호출마다 LLM 토큰 비용이 발생합니다. `budget` 으로 호출당 상한을 둡니다.
- **웨어하우스**: `AUTO_SUSPEND = 60`.
