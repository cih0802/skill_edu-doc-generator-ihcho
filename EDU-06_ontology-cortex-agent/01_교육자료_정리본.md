## 1. 학습 목표 및 완료 시 달성 상태

### 학습 목표
엔터프라이즈 관계형 스키마에 명시적으로 드러나지 않는 **도메인 온톨로지(계층 구조, 상속 관계, 유의어, 도메인 제약조건)**를 Snowflake의 네이티브 데이터 모델로 구축하고, AI Agent가 이를 바탕으로 신뢰성 높은 질의 응답과 분석을 수행할 수 있도록 엔드투엔드 파이프라인을 실습합니다.

### 완료 시 달성 상태
1. **온톨로지 데이터 모델링:** 엔티티(`KG_NODE`)와 관계(`KG_EDGE`)를 Snowflake 정규 테이블로 구축하고 속성을 JSON/VARIANT로 구조화할 수 있다.
2. **Recursive CTE 그래프 순회:** 다단계 상위/하위 계층 탐색 및 사이클 방지 경로 조회를 SQL 기반 Stored Procedure로 구현할 수 있다.
3. **Flattened GraphRAG 파이프라인:** 계층 순회 결과를 상위 노드로 롤업 집계한 비정형 프로파일 테이블을 생성하고, Cortex Search 기반 하이브리드 검색 서비스를 구성할 수 있다.
4. **Cortex Agent 그라운딩 및 용어 매핑:** 의미론적 유의어 해석과 프롬프트 수준의 용어 매핑 가이드라인을 주입하여 에이전트 추론 정확도를 향상시킬 수 있다.
5. **완전한 리소스 수명주기 관리:** 실습에 사용된 모든 스토리지, 컴퓨트, 서비스 리소스를 멱등하게 원복·정리할 수 있다.

## 2. 4대 아키텍처 패턴 비교 및 벤치마크 결과

Snowflake 엔지니어링 벤치마크(바이오메디컬 22개 고난도 질의)에서 도출된 4가지 접근법의 구조와 성능 지표입니다:

```
┌────────────────────────────────────────────────────────────────────────────────────────┐
│                        Snowflake Cortex Agent 추론 발전 단계                           │
└────────────────────────────────────────────────────────────────────────────────────────┘

1. Baseline Semantic View           2. Knowledge Graph (KG)
   ┌──────────────────────┐            ┌──────────────────────┐
   │ Cortex Analyst (SQL) │            │ 7 Tools (Stored Proc)│
   └──────────┬───────────┘            └──────────┬───────────┘
              ▼                                   ▼
   정확도: 50.0% (Score 0.93)           정확도: 60.0% (Score 1.14)
   * 한계: 도메인 계층 인식 불가        * 특징: 정확한 계층 탐색, 오케스트레이션 복잡도 증가

3. Flattened GraphRAG               4. GraphRAG + Terminology Mapping
   ┌──────────────────────┐            ┌──────────────────────┐
   │ Search + Analyst (2) │            │ Search + Analyst +   │
   └──────────┬───────────┘            │ System Prompt Rules  │
              ▼                        └──────────┬───────────┘
   정확도: 70.0% (Score 1.38)                     ▼
   * 특징: 사전 집계 인덱스,            정확도: 78.2% (Score 1.55)
     낮은 분산, 단순한 구조             * 특징: 복합 개념 매핑 해결, 최고 성능
```

| 접근 방식 | 도구 개수 | 평가 점수 (/2.0) | 성공률 (%) | 핵심 장점 및 트레이드오프 |
| :--- | :---: | :---: | :---: | :--- |
| **Standard Semantic View (Baseline)** | 1 | 0.93 | 50.0% | 기본 관계형 스키마 기반 질의 생성. 도메인 계층 구조/유의어 부재 시 한계 |
| **Baseline with Knowledge Graph** | 7 | 1.14 | 60.0% | Stored Procedure 기반 재귀 탐색. 계층 확장 정확하나 도구 오케스트레이션 복잡도 높음 |
| **Baseline with Flattened GraphRAG** | 2 | 1.38 | 70.0% | 사전 롤업 프로파일 + Cortex Search. 단순한 2-도구 아키텍처, 뛰어난 유의어 해결, 낮은 분산 |
| **GraphRAG + Terminology Mapping** | 2 | 1.55 | 78.2% | 복합어/도메인 특화 별칭 규칙을 프롬프트에 주입하여 라스트 마일 오류 완전 해소 |

## 4. 명명 규칙 (Naming Conventions)

1. **접두사 규격**: 모든 Snowflake 계정 레벨 및 데이터베이스 객체는 `EDU06_IHCHO_` 접두사를 사용합니다.
2. **테이블/뷰**: 대문자 스네이크 표기법 (`KG_NODE`, `KG_EDGE`, `KG_FLATTENED_PROFILES`)
3. **프로시저**: `SP_` 접두사 + 대문자 동사형 (`SP_GET_ANCESTORS`, `SP_EXPAND_COHORT`)
4. **Cortex Search 서비스**: `_SEARCH_SERVICE` 접미사 (`ONTOLOGY_SEARCH_SERVICE`)

## 6. 비용 및 리소스 관리

- **지속 과금 리소스**: Cortex Search 서비스(`ONTOLOGY_SEARCH_SERVICE`)는 인덱스 서빙을 유지하므로 실습 완료 후 반드시 중지 또는 삭제해야 합니다.
- **웨어하우스 비용**: 가상 웨어하우스(`EDU06_IHCHO_ONTOLOGY_WH`)는 `AUTO_SUSPEND = 60` 설정으로 유휴 비용을 최소화합니다.
- **정리 절차**: 실습 완료 즉시 `98_리소스정리.sql`을 실행하여 모든 잔여물을 0으로 만듭니다.
