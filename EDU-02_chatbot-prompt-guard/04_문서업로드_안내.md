# 04. 문서 업로드 안내 (Snowflake 외부 / UI 작업)

이 단계는 SQL 워크시트에서 끊김 없이 진행되지 않습니다. **Snowsight UI 또는 로컬
CLI에서 파일을 업로드**해야 하므로 별도 문서로 분리했습니다.

- **예상 소요 시간**: 약 10분 (문서 크기에 따라 다름)
- **선행**: `03_문서스테이지_및_디렉터리테이블.sql` 완료 (`DOC_STAGE` 존재)
- **후행**: `05_보안UDF_및_PII마스킹.sql`

> ⚠️ 이 단계는 파일 업로드라는 대화형 작업이므로 현재 계정에서 자동 검증되지
> 않았습니다. 아래 확인 쿼리는 업로드 후 실습자가 직접 실행해 결과를 확인하십시오.

---

## 1. 업로드할 문서 선정

| 항목 | 권장 |
|------|------|
| 형식 | PDF (권장), DOCX, PPTX, 이미지 |
| 건수 | **1~3건** — 실습 목적이므로 소량으로 시작합니다 |
| 페이지 | 문서당 10페이지 이하 권장 |
| 내용 | 사내 규정집, 보안 정책, 업무 매뉴얼 등 검색 대상이 될 문서 |

> 🔴 **실제 개인정보가 포함된 문서를 실습에 쓰지 마십시오.**
> `05_` 의 PII 마스킹 UDF는 정규식 기반이며 모든 형태의 개인정보를 잡지 못합니다.
> 마스킹 동작을 확인하려면 **가상의 연락처·주민번호를 넣은 테스트 문서**를 쓰십시오.

---

## 2. 업로드 방법

### 옵션 A — Snowsight UI (권장)

1. Snowsight 좌측 메뉴에서 **Data » Databases** 이동
2. `KSM_CHATBOT_DB` » `BRONZE` » **Stages** » `DOC_STAGE` 선택
3. 우측 상단 **+ Files** 클릭
4. 파일을 드래그하거나 선택 → **Upload**

> 역할이 `KSM_CHATBOT_ADMIN_ROLE` 인지 확인하십시오. 우측 상단 역할 선택기에서
> 바꿀 수 있습니다. 다른 역할이면 스테이지가 보이지 않습니다.

### 옵션 B — Snowflake CLI (로컬 파일)

로컬 터미널에서 실행합니다. Snowsight 워크시트에서는 `PUT` 을 실행할 수 없습니다.

```bash
snow stage copy ./내문서.pdf @KSM_CHATBOT_DB.BRONZE.DOC_STAGE \
  --role KSM_CHATBOT_ADMIN_ROLE
```

### 옵션 C — 사내 시스템 자동 동기화 (운영 단계)

NAS·SharePoint 등에서 정기적으로 스테이지에 전송하는 구성은 실습 범위를 벗어납니다.
설계 항목은 `91_사내연계_요청서.md` 를 참고하십시오.

---

## 3. 업로드 확인 — SQL 워크시트로 돌아와 실행

```sql
USE ROLE KSM_CHATBOT_ADMIN_ROLE;
USE WAREHOUSE KSM_CHATBOT_WH;

-- 디렉터리 테이블 메타데이터 동기화
ALTER STAGE KSM_CHATBOT_DB.BRONZE.DOC_STAGE REFRESH;

-- 업로드된 파일 확인
SELECT RELATIVE_PATH, SIZE, LAST_MODIFIED, MD5
FROM DIRECTORY(@KSM_CHATBOT_DB.BRONZE.DOC_STAGE)
ORDER BY LAST_MODIFIED DESC;
```

기록:

- 업로드한 파일 개수: `______` 개
- 파일명: `________________________________________________`
- `SIZE` 가 0 인 파일이 있는가: ☐ 없음 ☐ 있음 → 있으면 재업로드하십시오

---

## 4. 파일이 보이지 않을 때

| 증상 | 원인 | 조치 |
|------|------|------|
| `DIRECTORY()` 가 0행 | `REFRESH` 미실행 | `ALTER STAGE ... REFRESH` 실행 |
| 스테이지가 UI에 없음 | 역할이 다름 | `KSM_CHATBOT_ADMIN_ROLE` 로 전환 |
| 업로드 버튼이 비활성 | 스테이지에 대한 쓰기 권한 없음 | `02_` 의 소유권 이전([6]) 완료 여부 확인 |
| `SIZE` 가 0 | 업로드 중단 | 파일을 삭제하고 재업로드 |

---

## 5. 실습을 여기서 중단하는 경우

업로드한 파일은 **스토리지 비용**이 발생합니다. 파일만 지우려면:

```sql
-- 특정 파일 삭제
REMOVE @KSM_CHATBOT_DB.BRONZE.DOC_STAGE/내문서.pdf;

-- 스테이지 내 전체 파일 삭제
REMOVE @KSM_CHATBOT_DB.BRONZE.DOC_STAGE;

ALTER STAGE KSM_CHATBOT_DB.BRONZE.DOC_STAGE REFRESH;
```

전체 정리는 `98_리소스정리.sql` 이 정본입니다.
