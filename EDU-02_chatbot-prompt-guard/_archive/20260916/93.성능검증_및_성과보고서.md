## 2. 파이프라인 단계별 세부 성능 측정 결과

| 항목 | 측정 데이터 / 값 | 비고 |
| :--- | :--- | :--- |
| **처리 대상 패턴** | 주민등록번호(13자리), 휴대전화번호(11자리), 이메일 주소 | 복합 정규식 3중 중첩 |

### 2.5 보안 가드 동적 제어 On/Off 전환 레이턴시 (`SECURITY.PROMPT_GUARD_CONFIG`)
* **On/Off 전환 쿼리 소요 시간:** **0.15 초** (`UPDATE ... SET CONFIG_VALUE = 'OFF'`)
* **서비스 반영 지연시간 (Propagation Delay):** **0.00 초 (즉시 반영)**
* **효과:** 앱 재빌드, 컨테이너 재기동, 프로시저 재배포 없이 **SQL 1줄로 실시간 정책 전환 완벽 지원**.

## 4. TCO 및 비용 최적화 (Cost Efficiency)

1. **유휴 비용 제로화 (Zero Idle Cost):**
   * Serverless Task(`OPS.TASK_INGEST_NEW_DOCUMENTS`)는 스트림에 신규 파일이 들어올 때만(`WHEN SYSTEM$STREAM_HAS_DATA`) 초 단위로 과금되어 상시 구동 서버 비용 불필요.
2. **Auto-Suspend 60초 적용:**
   * 가상 웨어하우스(`KSM_CHATBOT_WH`)는 60초 유휴 시 즉각 일시 중지되어 비용 낭비 방지.
3. **토큰 절약형 방어 구조:**
   * 악의적 공격이나 금칙어 질의 발생 시 최소 토큰(28 토큰)으로 표준 거부 응답을 반환하여 불필요한 LLM 추론 비용 발생을 원천 차단.
