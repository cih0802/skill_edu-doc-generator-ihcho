# EDU-05. Apache Iceberg 테이블 종합 실습 가이드
### Snowflake Horizon Catalog + Iceberg Lakehouse Architecture

## 1. 학습 목표와 완료 상태

| # | 목표 | 완료 시 확인할 수 있는 것 (결과 쿼리) |
|---|------|------|
| 1 | **Snowflake-Managed** 및 **Customer-Managed(External Volume)** 스토리지 아키텍처 차이를 이해하고 환경을 구축한다 | `02_`, `03_` 전용 역할(`ICEBERG_LAB_RL`), 웨어하우스, DB, 스키마, External Volume DDL 검증 |
| 2 | Iceberg Table 생성(DDL) 및 **정형 데이터 + 반정형(JSON VARIANT)** 데이터를 적재한다 | `04_` `icb_vehicle_registry`, `icb_sensor_readings`, `icb_maintenance_logs` 적재 확인 및 `SYSTEM$GET_ICEBERG_TABLE_INFORMATION` |
| 3 | Iceberg 메타데이터 파일 구조(스냅샷, 매니페스트)와 **Time Travel** 기능을 실습한다 | `05_` `METADATA_VERSION` 조회, `AT (OFFSET => ...)` 타임트래블 쿼리 및 변경분 비교 |
| 4 | **Dynamic Iceberg Tables**를 사용하여 2단계(Tier 1 정제 -> Tier 2 집계) 증분 파이프라인을 구축한다 | `06_` `dit_enriched_telemetry`, `dit_daily_fleet_summary` 데이터 흐름 및 `REFRESH` 결과 |
| 5 | **Snowpark Python**을 통해 Iceberg 테이블 데이터를 프로그래밍 방식으로 정제 및 변환한다 | `07_` Snowpark 저장 프로시저(`SP_TRANSFORM_ICEBERG_TELEMETRY`) 실행 및 변환 테이블 생성 확인 |
| 6 | Iceberg 테이블에 **Row Access Policy(행 보안)** 및 **Masking Policy(열 마스킹)**를 적용한다 | `08_` 관리자/일반 사용자 역할 전환(`ICEBERG_ANALYST_RL`)에 따른 마스킹 및 행 필터링 결과 |
| 7 | Iceberg 테이블 대상 **Secure View** 및 **Outbound Data Share**를 구성한다 | `09_` `SHOW SHARES`, `sv_fleet_monitoring_public` 공유 상태 확인 |
| 8 | **Semantic View** 및 **Horizon Catalog**를 통해 외부 쿼리 엔진(DuckDB, Spark)과의 상호운용성을 확보한다 | `10_` `cortex_semantic_views` 확인, DuckDB/Spark용 Horizon Catalog 연결 엔드포인트 및 메타데이터 추출 |
| 9 | 계정에 어떤 잔여 리소스도 남기지 않고 완벽하게 정리한다 | `98_` PART D 정리 검증 쿼리 0건 확인 + 2회 연속 실행 안전성 확보 |

| :--- | :--- | :--- | :--- | :--- |
| **스토리지 옵션** | Snowflake-Managed 기본 스토리지 | External Volume (S3/Azure/GCS) | External Volume (AWS IAM + S3) | **두 모델을 모두 다룸: 클라우드 설정 없이 즉시 가능한 Snowflake-Managed를 기본으로 실습하고, External Volume 생성 문법과 IAM 구조를 명확히 비교** (`03_`) |
| **테이블 스키마** | 차량 플릿(차량 마스터, 센서, 정비로그) | 고객/주문 테이블 | 트럭 리뷰 테이블 | **차량 플릿 IoT & 정비 데이터를 채택하여 정형, 시계열, JSON VARIANT, 외부 테이블 비교를 포괄** (`04_`) |

| **상호운용성 & AI**| Horizon Catalog, DuckDB, Spark, CoWork | DuckDB, Spark | 메타데이터 파일 심층 분석 | **Iceberg 메타데이터 해부(`05_`), Semantic View 정의, DuckDB/Spark 연동 코드(`10_`)** |
